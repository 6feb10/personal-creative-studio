# DreamStudio

創作を、ひとつの場所に。プロット・キャラクター・AI生成・ノベル・画像・メモ・ブックマークをまとめる、一般向けのシンプルな創作管理アプリです。

スマホでもPCでも使えるPWAとして、創作に必要な情報を「小さなスタジオ」に集めることを目指しています。

---

## 2つのエディション — どちらを選ぶ？

DreamStudio は運用環境にあわせて2つの版から選べます。

| | 🖥️ **Server版** | 📱 **Local版** |
|---|---|---|
| **対象** | レンタルサーバーを持っている人 | サーバーを持っていない人 |
| **技術** | PHP + MySQL | 静的PWA（ブラウザ内DB） |
| **データ保存** | サーバーのDB | 端末のブラウザ内（IndexedDB） |
| **複数端末** | ◎ どこからでも同じデータ | △ バックアップファイルで引っ越し |
| **ログイン認証** | ◎ あり | なし（端末＝本人） |
| **オフライン** | △ | ◎ 一度開けば利用可 |
| **料金** | サーバー代（月数百円〜） | **完全無料** |
| **導入** | ファイル設置＋DB作成 | 静的ホスティングに置くだけ |
| **AI生成** | サーバーにキーを保存（安全） | 自分のAPIキーを貼って利用（任意） |
| **フォルダ** | [`server/`](server/) | [`local/`](local/) |

### どちらにすべき？

- **スマホとPCで同じデータを使いたい／ちゃんとログインしたい** → **Server版**（[`server/`](server/)）
- **お金をかけたくない／登録なしですぐ使いたい／オフラインでも** → **Local版**（[`local/`](local/)）

> どちらの版も、AIなしでも創作管理機能を使えます。AI生成・対話・挿絵プロンプトは、APIキーを設定すると使える「任意の相棒」機能です。

## Local版の機能（7つの部屋）

noteで紹介している GitHub Pages 公開版は、`local/` の中身を公開する Local版です。

| 部屋 | 機能 |
|---|---|
| 📚 **プロット / Memoria** | 物語の設定、ナレッジ、AIへのカスタム指示、関連リンク |
| 🏠 **キャラクター / Cradle** | 拠点となる世界と、そこに住む登場人物の設計 |
| ✨ **AI生成 / Forge** | 物語生成、キャラ対話、挿絵プロンプト、テンプレート、使用量確認 |
| 📖 **ノベル / Desire** | 小説の保存・編集、ギャラリー画像の挿入 |
| 🖼️ **ギャラリー / Reverie** | キャラ画像・参考画像の保存、タグ棚、並び替え |
| 💡 **メモ / Spark** | 走り書き、タスク、「あとで」用の小さなメモ |
| 🔖 **ブックマーク / Sanctum** | 創作資料リンクやAPIプラットフォームなどの資料棚 |

### Server版について

Server版は現時点では **6つの門**（Cradle / Forge / Desire / Reverie / Memoria / Sanctum）構成です。ログイン式で、データはMySQLに保存されます。
