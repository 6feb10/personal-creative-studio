# DreamStudio

創作を、ひとつの場所に。物語・キャラクター・画像・AI生成をまとめる、一般向けのシンプルな創作管理アプリです。

世界設定・ノベル執筆・画像ギャラリー・プロジェクト管理・ブックマーク・AI生成・キャラ対話を、ひとつのモバイル対応PWAに統合しています。

---

## 2つのエディション — どちらを選ぶ？

DreamStudio は **同じ機能・同じ見た目** で、運用環境にあわせて2つの版から選べます。

| | 🖥️ **Server版** | 📱 **Local版** |
|---|---|---|
| **対象** | レンタルサーバーを持っている人 | サーバーを持っていない人 |
| **技術** | PHP + MySQL | 静的PWA（ブラウザ内DB） |
| **データ保存** | サーバーのDB | 端末のブラウザ内（IndexedDB） |
| **複数端末** | ◎ どこからでも同じデータ | △ バックアップファイルで引っ越し |
| **ログイン認証** | ◎ あり | なし（端末＝本人） |
| **オフライン** | △ | ◎ 完全に動く |
| **料金** | サーバー代（月数百円〜） | **完全無料** |
| **導入** | ファイル設置＋DB作成 | 静的ホスティングに置くだけ |
| **AI生成** | サーバーにキーを保存（安全） | 自分のAPIキーを貼って利用（任意） |
| **フォルダ** | [`server/`](server/) | [`local/`](local/) |

### どちらにすべき？
- **スマホとPCで同じデータを使いたい／ちゃんとログインしたい** → **Server版**（[`server/`](server/)）
- **お金をかけたくない／登録なしですぐ使いたい／オフラインでも** → **Local版**（[`local/`](local/)）

> どちらの版も、AIなしでも創作管理（世界設定・ノベル・ギャラリー・プロジェクト・ブックマーク）はフルに使えます。AI生成・対話・挿絵はAPIキーを設定すると解放される「おまけ」です。

## 共通の機能（6つの門）

| 門 | 機能 |
|---|---|
| 🏠 **Cradle** | 拠点とキャラクターの世界設計 |
| ✨ **Forge** | AI生成ワークステーション |
| 📖 **Desire** | ノベル管理（画像埋め込みのビジュアルノベル表示） |
| 🖼️ **Reverie** | 画像ギャラリー |
| 📚 **Memoria** | プロジェクト／ナレッジ管理 |
| 🔖 **Sanctum** | ブックマーク |
