# DreamStudio — Server版（PHP + MySQL）

> これは **サーバーを持っている人向け** のエディションです。サーバー不要の静的版は [`../local/`](../local/)、版の比較は [リポジトリのREADME](../README.md) を参照してください。

創作を、ひとつの場所に。物語・キャラクター・画像・AI生成をまとめる、一般向けのシンプルな創作管理 PWA。

PHP + MySQL のレンタルサーバー1つで動く、フレームワーク不使用のセルフホスト型アプリです。スマートフォンのホーム画面に追加して、アプリのように使えます。

## 機能（6つの門）

| 門 | 機能 |
|---|---|
| 🏠 **Cradle** | 拠点とキャラクターの世界設計（パラメーター・関係性・設定管理） |
| ✨ **Forge** | AI生成ワークステーション（複数プロバイダー対応・テンプレート・使用量ダッシュボード） |
| 📖 **Desire** | ノベル管理（執筆・タグ・画像埋め込みのビジュアルノベル表示） |
| 🖼️ **Reverie** | 画像ギャラリー（アップロード・フォルダ・タグ・ノベル逆引き） |
| 📚 **Memoria** | プロジェクト／ナレッジ管理（カスタム指示・ペルソナ・素材紐づけ） |
| 🔖 **Sanctum** | ブックマーク（URL・フォルダ・タグ） |

このほか、キャラクター対話・挿絵プロンプト生成などの AI 補助機能を備えています。

## 技術スタック

- バックエンド: PHP 8.x（フレームワーク不使用）
- データベース: MySQL（InnoDB / utf8mb4）
- フロントエンド: HTML / CSS / Vanilla JavaScript
- 配信: PWA（manifest.json + Service Worker）

## 導入手順

1. PHP + MySQL 対応のサーバーにファイル一式をアップロード
2. MySQL でデータベースを作成
3. `config.php` の `DB_HOST` / `DB_NAME` / `DB_USER` / `DB_PASS` を設定
4. ブラウザで `install.php` にアクセス → テーブル作成と管理ユーザー登録
5. **`install.php` を削除**
6. `login.php` からサインインして利用開始

> テーブル定義は `schema.sql` にまとまっています。手動で流し込むことも可能です。

## テーマのカスタマイズ

`css/style.css` 先頭の CSS 変数（`:root`）を書き換えるだけで、配色を一括変更できます。

```css
:root {
  --void: #faf7f5;   /* 背景 */
  --orchid: #7c5cff; /* アクセント */
  --blush: #ff7eb6;  /* セカンダリ */
  --pearl: #241c30;  /* 見出しテキスト */
  /* ... */
}
```

## セキュリティ

- セッションベース認証（`password_hash`）
- 全 POST で CSRF トークン検証
- PDO プリペアドステートメント（SQLインジェクション対策）
- `htmlspecialchars` による出力エスケープ（XSS対策）
- API キーはサーバーサイドのみで参照（ブラウザ非露出）
