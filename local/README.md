# DreamStudio — Local版（静的PWA）

> これは **サーバーを持っていない人向け** のエディションです。PHP+MySQL版は [`../server/`](../server/)、版の比較は [リポジトリのREADME](../README.md) を参照してください。

サーバーもデータベースも不要。**ブラウザだけで動く**完全プライベートな創作スタジオです。データはすべてこの端末のブラウザ内（IndexedDB）に保存され、外部には送られません。

## 特長
- **登録・ログイン不要** — 開いたらすぐ使える
- **完全無料・オフライン動作** — インターネットが無くても使える
- **インストール可能** — スマホのホーム画面に追加してアプリ化
- **AIはおまけ** — 創作管理（世界設定・ノベル・ギャラリー・プロジェクト・ブックマーク）はAIなしでフル機能。AI生成・対話・挿絵は、設定で自分のAPIキーを入れると解放されます

## 使い方（設置する人）
ビルド不要の静的ファイルです。以下のどれかに `local/` の中身を置くだけ:
- GitHub Pages / Netlify / Cloudflare Pages（無料）にアップロード
- もしくはローカルで試す:
  ```
  cd local
  python3 -m http.server 8000   # または: php -S 127.0.0.1:8000
  ```
  ブラウザで `http://127.0.0.1:8000/` を開く

> ⚠ `file://` で直接開くと Service Worker や一部機能が動きません。必ず http(s) で配信してください。

## データの保存とバックアップ
- データはこのブラウザ内だけに保存されます（端末・ブラウザを変えると引き継がれません）
- **設定 → バックアップ** から、全データを1ファイル（JSON）で書き出し/読み込みできます。端末の引っ越しや保存にお使いください

## AIを使う場合
1. 各社でAPIキーを取得（OpenAI / Anthropic / Google など）
2. **設定 → AIキー** でプロバイダーを追加し、キーを貼り付け
3. キーはこの端末内だけに保存されます

> 注: ブラウザから直接AIを呼ぶ仕様のため、プロバイダーによっては接続できない場合があります（CORS）。Gemini や Claude は比較的通りやすいです。

## 技術
- HTML / CSS / Vanilla JavaScript（ビルド工程なし・依存ゼロ）
- IndexedDB（データ）/ Service Worker（オフライン）/ PWA
