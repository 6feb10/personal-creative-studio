# DreamStudio — Local版（静的PWA）

> これは **サーバーを持っていない人向け** のエディションです。PHP+MySQL版は [`../server/`](../server/)、版の比較は [リポジトリのREADME](../README.md) を参照してください。

サーバーもデータベースも不要。**ブラウザだけで動く**、個人用の創作スタジオです。データはこの端末のブラウザ内（IndexedDB）に保存されます。

## 特長

- **登録・ログイン不要** — 開いたらすぐ使える
- **完全無料・オフライン動作** — インターネットが無くても使える
- **インストール可能** — スマホのホーム画面に追加してアプリ化
- **AIは任意** — 創作管理はAIなしでも利用可能。AI生成・対話・挿絵プロンプトは、設定で自分のAPIキーを入れると使えます

## 7つの部屋

| 部屋 | できること |
|---|---|
| 📚 **プロット** | 物語の設定、ナレッジ、AIへのカスタム指示、関連リンクを管理 |
| 🏠 **キャラクター** | 拠点となる世界と登場人物を設計 |
| ✨ **AI生成** | 物語生成、キャラ対話、挿絵プロンプト、テンプレート、使用量確認 |
| 📖 **ノベル** | 小説の保存・編集、ギャラリー画像の挿入 |
| 🖼️ **ギャラリー** | 画像保存、タグ棚、並び替え、ノベルへの挿絵利用 |
| 💡 **メモ** | 走り書き、タスク、「あとで」を放り込む場所 |
| 🔖 **ブックマーク** | 創作資料リンクやAPIプラットフォームなどの資料棚 |

## 使い方（設置する人）

ビルド不要の静的ファイルです。以下のどれかに `local/` の中身を置くだけ:

- GitHub Pages / Netlify / Cloudflare Pages（無料）にアップロード
- もしくはローカルで試す:

  ```
  cd local
  python3 -m http.server 8000   # または: php -S 127.0.0.1:8000
  ```

  ブラウザで `http://127.0.0.1:8000/` を開く

> ⚠ `file://` で直接開くと Service Worker や一部機能が動きません。必ず http(s) で配信してください。

## データ保存・プライバシー

- データはこのブラウザ内だけに保存されます（端末・ブラウザを変えると引き継がれません）
- **設定 → バックアップ** から、全データを1ファイル（JSON）で書き出し/読み込みできます。端末の引っ越しや保存にお使いください
- バックアップには画像データも含まれるため、画像が多いほどファイルは大きくなります
- APIキーはバックアップファイルに含まれません

通常の創作データを保存・収集するアプリ側サーバーはありません。ただし、外部通信には次の例外があります。

1. **AI機能を使うとき**  
   入力したプロンプト、選択したプロット・キャラクター設定、本文など、生成に必要な情報が、選択したAI会社のAPIへ直接送られます。

2. **画面フォント**  
   装飾フォントをGoogle FontsのCDNから読み込みます。

## AIを使う場合

1. 各社でAPIキーを取得（OpenAI / Anthropic / Google など）
2. **設定 → AIキー** でプロバイダーを追加し、キーを貼り付け
3. キーはこの端末内だけに保存されます

> 注: ブラウザから直接AIを呼ぶ仕様のため、プロバイダーによっては接続できない場合があります（CORS）。別モデルや別プロバイダーで試してください。

## 技術

- HTML / CSS / Vanilla JavaScript（ビルド工程なし・依存ゼロ）
- IndexedDB（データ）/ Service Worker（オフライン）/ PWA
